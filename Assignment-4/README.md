# Week 4 Assignment: Statistics, Data Visualization & EDA

## Project Overview

This repository contains my Week 4 assignment on Statistics, Data Visualization, and Exploratory Data Analysis (EDA).

The objective of this assignment is to apply statistical concepts, analyze datasets using Python, create meaningful visualizations, perform data cleaning, identify correlations and outliers, and develop data-driven insights and business recommendations.

The project includes Jupyter Notebooks, datasets, visualization screenshots, and EDA documentation.

## Objectives

- Calculate mean, median, mode, variance, and standard deviation.
- Perform correlation analysis and understand basic probability.
- Identify potential outliers using statistical methods.
- Create visualizations using Matplotlib and Seaborn.
- Inspect and clean datasets using Pandas.
- Identify missing values, duplicate records, and inconsistent values.
- Explore relationships, patterns, and trends in data.
- Develop meaningful insights and business recommendations.

## Tools and Technologies

- Seaborn
